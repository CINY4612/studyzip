# Node.js 백엔드 프레임워크 제작 업무 대비 4일 단기 플랜

## 목표

회사 입사 전 짧은 기간 동안 다음 역량을 빠르게 확보하는 것을 목표로 한다.

* Node.js 런타임 구조 이해
* Express 기반 서버 개발 경험
* 비동기 처리 흐름 이해
* WebSocket 기반 실시간 통신 경험
* 프레임워크 내부 구조 감각 습득
* Docker / Nginx 기반 서버 환경 이해

단순 문법 학습보다 실제 서버가 어떻게 동작하는지 흐름 중심으로 학습한다.

---

# 전체 학습 방향

## 1. “사용”보다 “동작 원리” 중심

단순 Express 사용법보다 아래 흐름을 이해하는 데 집중한다.

```text
클라이언트 요청
→ Router
→ Middleware
→ Handler
→ Response
```

또한 Node.js 의 핵심인 이벤트 기반 비동기 구조를 함께 학습한다.

---

## 2. Spring 경험과 연결해서 이해

기존 Spring Boot 경험과 매핑하여 학습 효율을 높인다.

| Spring            | Node.js        |
| ----------------- | -------------- |
| DispatcherServlet | Express Router |
| Filter            | Middleware     |
| Controller        | Controller     |
| Service           | Service        |
| Repository        | Repository     |
| Bean 흐름           | Module 흐름      |

---

## 3. 실시간 통신 이해 강화

회사 요구사항에 포함된 기술:

* WebSocket
* STOMP
* WebRTC

를 고려하여 실시간 서버 흐름을 이해하는 데 중점을 둔다.

특히 다음 구조를 이해하는 것을 목표로 한다.

```text
TCP
→ HTTP
→ WebSocket Upgrade
→ 실시간 양방향 통신
```

---

## 4. “프레임워크 제작” 관점으로 접근

회사의 업무 특성상 단순 API 개발보다 다음 능력이 중요하다.

* 요청 흐름 이해
* 미들웨어 구조 이해
* 이벤트 기반 처리 이해
* 서버 추상화 구조 이해

따라서 마지막 단계에서는 간단한 mini framework 형태까지 직접 구현해본다.
